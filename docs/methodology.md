# 收录与分类规则

检索截至 2026-10-09。主要依据摘要、官方发表元数据与作者论文仓库分类，不逐篇阅读全文，不进行性能排名。

| 范围 | 收录渠道 |
| :-- | :-- |
| 会议 | CVPR、ICCV、ECCV、NeurIPS、ICML、AAAI、MICCAI、ACM MM |
| 期刊 | TPAMI、TIP、IJCV、TMM、TCSVT、Information Fusion、Pattern Recognition、TGRS |

上述是主要渠道，个别具有明确领域代表性的工作（如 IEEE/CAA JAS 的 SwinFusion）允许经来源核查后例外收录。这是面向本次需求的主要渠道名单，不代表统一官方等级。主表仅收录发表信息已由作者来源或出版平台核对的记录；无已确认发表渠道的预印本、普通期刊与尚待核实的收藏存入 `archive/excluded-records.json`，不计入主索引。

按应用任务分表，研究问题及技术机制用交叉标签。语义先验不等于下游任务监督；文本只用于训练的方法不等于推理时可交互控制。通用模型可出现在多个应用入口。输出特征或分割、单图知识迁移、质量评价均另列，避免与双源像素融合混淆。

年份优先使用会议/期刊卷期年份，在线发表差异保留备注。每条 JSON 记录保存来源与核对日期。“有仓库”不等于有完整代码、可下载权重或已独立复现。本次未逐条测试全部外链的实时可访问性。

当前为精选索引，不是穷尽式系统综述；后续优先补齐医学、遥感、多曝光与较早的代表性工作。新增条目必须附论文原始来源。原始 README 完整保留在 archive。
